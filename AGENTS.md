# AI Development Guidelines

## Project

You are contributing to **ViziCheck**, a production-ready Smart Visitor Management System.

Always follow the project documentation before implementing any feature.

---

# Engineering Principles

* Write production-quality code.
* Prioritize readability over cleverness.
* Follow Clean Architecture.
* Follow SOLID principles where appropriate.
* Keep functions small and focused.
* Avoid code duplication.
* Build reusable components and services.
* Never implement undocumented business logic.

---

# Naming Standards

* Use descriptive variable names.
* Avoid one-letter variables except loop counters.
* Use meaningful class and function names.
* Keep naming consistent across the project.

---

# Code Quality

* Use async/await where applicable.
* Handle all expected errors.
* Remove unused code.
* Follow ESLint/Prettier formatting.
* Keep files modular and maintainable.

---

# Security

* Never hardcode secrets.
* Validate all inputs.
* Enforce RBAC permissions.
* Store secrets in environment variables.
* Never expose stack traces.

---

# Documentation

Whenever a feature changes:

* Update documentation if required.
* Maintain API consistency.
* Preserve architecture.

---

# Definition of Done

A task is complete only when:

* Requirements are met.
* Error handling is implemented.
* Validation is complete.
* Code is lint-free.
* Documentation is updated if needed.
* Existing architecture is respected.
